# 🌐 Ruya-Demos — Public Prospect Demo Websites

This repository contains static demo websites created by **Ruya AI Web Agency Engine** for cold prospect previews.

## 🚀 Live Hosting
Connected to **Cloudflare Pages**. Every commit pushed to `main` automatically deploys live to:
`https://ruya-demos.pages.dev/<safe-slug>/` (or `https://demo.ruya.ai/<safe-slug>/`).
